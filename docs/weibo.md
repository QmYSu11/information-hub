# 微博热搜接入

核实日期：2026 年 11 月 11 日。采用“微博公开接口优先，UAPI 免费公开榜单备用”，不需要用户注册微博开发者账户，也不需要填写密钥或登录 Cookie。

## 当前实测

| 来源 | 结果 | 使用方式 |
| --- | --- | --- |
| `https://weibo.com/ajax/side/hotSearch` | 本机无登录请求 HTTP 403 | 保留首选请求，若能正常返回真实榜单则直接使用 |
| `https://weibo.com/ajax/statuses/hot_band` | 本机无登录请求 HTTP 403 | 仅作验证记录，不增加重复失败轮询 |
| `https://uapis.cn/api/v1/misc/hotboard?type=weibo` | HTTP 200，50 条，含原始序号、热度和微博链接；榜单更新时间为本日 | 官方接口失败后只请求一次，界面明确注明 UAPI 第三方聚合 |

UAPI 的[服务文档](https://uapis.cn/docs/api-reference/get-misc-hotboard)说明当前热榜无需注册或 API Key，可直接调用；历史与搜索高级参数不在本项目使用范围内。该免费公开服务仍可能限流、调整政策或上游故障，不能承诺永久可用。本站默认随公开快照每半小时计划获取，不在访问者浏览页面时重复请求。

## 数据与故障规则

- 来源 ID 保持 `weibo-hot`，与原网站筛选、收藏及缓存兼容。
- 仅保存热词标题、来源提供的真实排名与热度、微博搜索链接，以及本站获取时间；不保存微博正文、用户资料或私人凭证。
- 不把去重或过滤后的条目重新排号，保留来源排名间隔；不虚构话题发布时间。
- UAPI 数据必须明确为当前 `weibo` 榜单，带有效且不超过两小时的上游更新时间。历史、搜索结果、无有效时间或明显未来数据不会作为当前热榜发布。
- 来源信息注明 UAPI 聚合，并显示榜单上游更新时间。本站 `lastSuccessAt` 是本次获取成功时间，与服务的榜单更新时间分别保留。
- 官方与备用都失败时，保留上一次真实条目、原获取时间、原成功时间及署名，并显示更新延迟；没有缓存则显示暂不可用。不会把失败重新计为成功，也不会发布演示热词。
- 链接只接受 `s.weibo.com/weibo` 的公开搜索链接，不接纳第三方跳转或携带账号密码的 URL。

规则测试位于 `tests/weibo.test.ts`，使用明确标记的本地样例；真实接通仍以联网采集和发布后的快照检查为准。

## 小红书热榜的额外核查

同一服务的 `type=xiaohongshu` 本次也返回 HTTP 200、20 个搜索热词，但其 `update_time` 停在 2026 年 10 月 27 日，已过期约两周，且链接指向热词搜索页，不是推荐帖原文。因此未把它接入为实时推荐流；小红书推荐帖子继续使用独立的 [SandBase 接入配置](xiaohongshu.md)，避免混淆热搜与推荐内容。
