## 3. 数据接入与透明度

当前真实来源为中新网国内、国际、财经、社会，NPR World、IT之家科技和 B 站综合排行榜。首份快照中 B 站有 40 条真实榜单内容，满足至少一个指定平台自动热榜的最低范围。详细端点与状态见 sources.md。

微博热搜在本次采集环境返回 HTTP 403，保留清楚标记的原站入口。小红书改为推荐帖子模块，SandBase 免费额度优先的适配与页面已完成，但无服务密钥，尚未完成有权限的成功获取。匿名请求实测 401，不使用文档示例填充页面，不计作已连接的自动内容源。完整接入步骤与范围见 [xiaohongshu.md](xiaohongshu.md)。

报价快照默认不保存未核实公开展示许可的腾讯数据；null 代表本站没有该报价，不是价格为零。新版使用自选看盘与官方行情组件，主图、摘要和研究面板跟随本站当前标的。网络、地区、来源授权及特定标的支持均可能影响显示。分钟周期不抵消数据延迟；A 股日终来源不能作为盘中实时报价。

所有发布时间与采集时间分开保留。generatedAt 只表示快照生成，不证明每个来源都刚刚成功更新；失败源沿用旧 fetchedAt 与 lastSuccessAt。

## 6. 发布文档与工作流核对

README 与 .github/workflows/pages.yml 的以下配置已逐项核对一致：

- 发布工作流名称为 Update information and publish Pages。
- main、master 分支推送和 workflow_dispatch 可触发；实际检出仓库默认分支。
- 定时计划为每小时第 7、37 分钟；该计划不构成严格的时间保证。
- Node.js 使用 24，安装使用 npm ci，依次执行采集、测试、快照集成检查、构建与发布。
- 构建环境变量为 BASE_PATH，与 vite.config.ts 读取项一致。
- 普通项目使用仓库子路径；仓库名以 .github.io 结尾时使用根路径。
- 快照在 data 分支持久化；个人数据仍保存在浏览器，不进入发布快照。
- 腾讯可选报价以 ENABLE_TENCENT_QUOTES 控制，默认关闭。
- 小红书服务密钥通过 Actions Secrets 的 SANDBASE_API_KEY 或 TIKHUB_API_KEY 注入采集步骤，不使用前端环境变量；两个均存在时优先 SandBase。
