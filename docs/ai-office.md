# 通用 AI 办公室

办公室处理工作、学习、写作、生活疑问，也提供有趣内容、自选观察模板。品牌不对应固定岗位：召集模型先为当前任务拟定分工，用户可编辑后确认，再执行工作、审阅与汇总。一个模型也能独立完成任务；未配置的模型不会由其他模型代扮。

新闻与热榜仍位于 GitHub Pages。真实模型调用需要登录的 owner-private Sites 服务，公开页面不保存密钥。独立服务可读源码在 ai-office-server/，数据库迁移分别为0001任务/调用预算、0002个人加密模型配置。私密服务中可以输入单个模型密钥，或选择本地 .env 文件，仅识别 OPENAI_API_KEY、DEEPSEEK_API_KEY、GEMINI_API_KEY；选择文件后仅预览发现的服务名，明确点击保存后才传至当前私密办公室。密钥按登录用户 AES-GCM 加密存入 D1，不进入公开快照、任务回复或浏览器持久存储。

每项任务可选3、4、6次调用，包含一次拟定分工；服务默认每日北京时间30次请求上限。次数上限不等于供应商金额预算，实际账单和额度由对应账户决定。默认不自动重试模型调用，失败即停止后续步骤。已发送的请求即使取消也可能计费。

用户任务及明确选中的资料会发给本次参与模型；个人笔记默认不发送。GitHub站点和私密站点是不同域名，本地笔记、自选不会自动跨域传输；私密页支持单独输入自选代码或明确选入材料。工作记录服务端临时保留一小时；恢复时仍限定原任务已同意参加的成员。

新闻精选只依据提供的标题与摘要，不宣称看完视频。股票观察仅整理本次材料，不虚构实时价格，不执行交易，不承诺网页关闭后的自动盯盘。网站不会执行模型输出的代码、访问任意链接或发送对外消息。

动漫角色为本站原创虚拟形象，与模型官方形象无关：澄海（DeepSeek）、知白（ChatGPT）、星野（Gemini）。人物只有视觉和性格设定，任务职责由本次分工决定。

OpenAI密钥已通过用户指定的安全设置流程创建到本地私密文件；本机俳句验证两次连接超时，没有取得OpenAI API响应，因此不标为调用验证成功。私密服务发布及真实多模型任务须另以线上结果确认；缺少密钥时只显示待连接，不生成演示对话。
