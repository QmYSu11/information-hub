# 通用 AI 办公室

办公室默认打开“连续对话”，处理工作、学习、写作、生活疑问，也提供有趣内容、视频推荐和自选动态入口。可以在同一会话里不断追问，每条用户消息调用所选模型一次；新会话优先选择已配置的 DeepSeek，其他模型连接完整保留，可手动选择。

原有流程保留在“小队协作”：召集模型先为当前任务拟定分工，用户可编辑后确认，再执行工作、审阅与汇总。品牌不对应固定岗位，一个模型也能独立完成任务；未配置的模型不会由其他模型代扮。

新闻与热榜仍位于 GitHub Pages。真实模型调用需要登录的 owner-private Sites 服务，公开页面不保存密钥。独立服务可读源码在 ai-office-server/，数据库迁移分别为0001任务/调用预算、0002个人加密模型配置、0003连续对话。私密服务中可以输入单个模型密钥，或选择本地 .env 文件，仅识别 OPENAI_API_KEY、DEEPSEEK_API_KEY、GEMINI_API_KEY；选择文件后仅预览发现的服务名，明确点击保存后才传至当前私密办公室。密钥按登录用户 AES-GCM 加密存入 D1，不进入公开快照、任务回复或浏览器持久存储。

小队协作每项任务可选3、4、6次调用，包含一次拟定分工；连续对话每条消息一次调用。两种方式共用每日北京时间30次请求上限。次数上限不等于供应商金额预算，实际账单和额度由对应账户决定。默认不自动重试模型调用，失败即停止后续步骤。已发送的请求即使取消也可能计费。

用户任务及明确选中的资料会发给本次参与模型；个人笔记默认不发送。GitHub站点和私密站点是不同域名，本地笔记、自选不会自动跨域传输；私密页支持单独输入自选代码或明确选入材料。工作记录服务端临时保留一小时；恢复时仍限定原任务已同意参加的成员。

连续对话按当前登录账号分别保存，可从历史列表恢复，服务端保留30天。一次会话固定使用一个模型；切换模型需要开启新对话，不会把已有历史暗中发给另一家模型。模型上下文有数量与长度界限，界面显示实际带入的消息数；失败尝试不伪装成已完成回复，也不会进入下一轮成功上下文。

普通聊天不默认附新闻、自选或笔记。选择“挑点有趣的”“推荐视频”“自选动态”会明确列出所附新闻材料与时间，支持刷新资料；引用只能跳转实际提供的原帖、报道或视频。新闻精选只依据标题与摘要，不宣称看完视频。股票动态使用明确填写的自选代码和财经新闻，不虚构实时价格；现有实时K线继续在公开站的行情页查看。办公室不会在网页关闭后自动盯盘，也不会执行模型输出的代码、访问任意链接或发送对外消息。

动漫角色为本站原创虚拟形象，与模型官方形象无关：澄海（DeepSeek）、知白（ChatGPT）、星野（Gemini）。人物只有视觉和性格设定，任务职责由本次分工决定。

密钥保存成功不等于供应商请求成功；真实调用返回的认证、额度、请求格式或网络错误会明确显示。缺少密钥时只显示待连接，不生成演示对话。
